# SNAYZA Cybersecurity Toolkit

A small Python terminal project for learning basic cybersecurity concepts <33

![image alt](https://github.com/Snayza/SNAYZA-Cybersecurity-Toolkit/blob/2e483a5d102553ee6cdae1d3f1ba71e02187d75d/Screenshot%202026-10-11%20211655.png)

## Features

The interface uses a simple black-and-red terminal style (color support depends on your terminal).

- **Password Strength Checker** — gives a rough estimate based on length and character variety. It does not save or transmit the entered text.
- **Phishing URL Checker** — looks for a few visible URL warning signs without opening the website.
- **Cybersecurity Tips** — displays practical online-safety reminders.

## Requirements

- Python 3.10 or newer
- No third-party packages required

## Run it

1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run:

   ```bash
   python main.py
   ```

   On some systems, use `python3 main.py` instead.

## Important limitations

This is an educational project, not a professional security scanner. Password ratings are only rough estimates. The URL checker does not visit sites, verify certificates, or query threat-intelligence services. A URL with no warning can still be malicious. Never enter a real password into a demo or tool you do not trust.
